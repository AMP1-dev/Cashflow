# Portal Corporativo Universo AMP

Portal institucional unificado para o **Grupo AMP**, reunindo mais de 40 anos de excelência e liderança em gestão corporativa de TI, governança, infraestrutura em nuvem, cibersegurança, consultoria contábil-tributária e planejamento estratégico.

---

## 🌐 Ecossistema de Ativos Integrados

1. **Aliança Empresarial (Case de Sucesso)** — [https://aliancaempresarial.net.br](https://aliancaempresarial.net.br)
   - Case Corporativo: Gestão Integral de TI, Cibersegurança Ativa, Infraestrutura em Nuvem e Desenvolvimento Web de Alto Desempenho.
2. **MeshCentral Suporte Remoto** — [https://remoto.amp.ia.br](https://remoto.amp.ia.br)
   - Plataforma centralizada de acesso remoto seguro, NOC 24/7, monitoramento proativo de servidores e helpdesk corporativo.
3. **Projeto João de Barro** — [https://projetojoaodebarro.org.br](https://projetojoaodebarro.org.br)
   - Iniciativa de responsabilidade socioambiental, capacitação digital e desenvolvimento comunitário apoiada pelo Grupo AMP.
4. **Rádio Amplificadora** — [https://amplificadora.com.br](https://amplificadora.com.br)
   - Plataforma de mídia, cultura e inovação sonora do Grupo AMP (com web rádio ao vivo integrada ao portal).

---

## 🚀 Principais Funcionalidades do Portal

- **Hero Corporativo de Autoridade**: Destaque para os 40+ anos de história, KPIs em tempo real (+500 empresas atendidas, 15.000+ dispositivos gerenciados, R$ 250M+ em otimizações financeiras e SLA < 15 min).
- **Vitrine do Ecossistema AMP**: Seção imersiva com cards interativos, dossiês detalhados e acesso direto aos 4 ativos da marca.
- **Portfólio de Soluções Corporativas**:
  - *TI Corporativa & Cloud*: Nuvem híbrida (AWS/Azure), Cibersegurança & Backup Imutável, Suporte Gerenciado 24/7 e Governança de TI / IA Corporativa.
  - *Consultoria Financeira & Estratégica*: BPO Financeiro Integral, Planejamento Tributário & Elisão Fiscal, DRE Gerencial / Valuation e Holding Patrimonial.
- **Agendamento de Diagnóstico 360° Interativo**: Wizard inteligente em 3 etapas com mapeamento de dores e cálculo automático de potencial de otimização, com direcionamento ao WhatsApp da diretoria.
- **Cases de Sucesso com Métricas Reais**: Exemplos reais de transformação nos setores hospitalar, industrial e logístico.
- **Central de Clientes (Client Hub)**: Acesso rápido a sistemas, NOC, suporte remoto e canais prioritários.
- **Artigos Técnicos & Insights**: Publicações sobre cibersegurança, reforma tributária, BPO e governança.
- **Player de Áudio Integrado (Rádio Amplificadora)**: Dock flutuante com streaming contínuo em 320kbps ao vivo.
- **Painel Executivo da Diretoria (Admin)**: Gerenciador de Leads, Diagnósticos 360°, Serviços Corporativos, Artigos e Backup/Restauração de dados em JSON.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React 18, Vite 5, Tailwind CSS
- **Ícones:** Lucide React
- **Áudio Streaming:** HTML5 Audio Stream Zeno FM (Rádio Amplificadora)
- **Persistência Local:** localStorage & sessionStorage com suporte a backup/restore completo

## 💻 Como Rodar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Executar o servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build
```
